# Renaissance Technologies 开源 repo 专刊

Renaissance 的 GitHub 足迹为零，而且**永远会是零**——它是保密光谱
的绝对终点。本专刊记录「为什么」以及「公开资产在哪里」。

## 公开资产

| 资产 | 是什么 |
|---|---|
| 《The Man Who Solved the Market》| Zuckerman 的传记——外界了解 RenTec 的唯一完整窗口 |
| 大奖章业绩数据 | 1988-2018 费前 ~66% 年化（多个公开来源交叉验证）|
| Simons 基金会 | Flatiron Institute 等基础科学资助——另一种「开源」（开科学）|

## 为什么零开源

1. **模型即一切**：RenTec 没有「框架」与「策略」之分——什么都可能
   泄露 alpha
2. **神秘感是资产**：沉默让品牌神话自我强化
3. **无任何外部需求**：不募资（自营为主）、不招聘营销（名声自带流量）

## 对 dsh-quant 的启发

1. **光谱终点的意义**：有了 RenTec 这个终点，整个光谱才完整——
   从「连框架都开源」（JS）到「什么都不说」（RenTec）
2. **dsh-quant 的位置**：我们选「方法公开、秘密内部」——不是
   RenTec 的极端，因为个人开发者需要**开源换生态位**，而 RenTec
   不需要生态位
3. **规模克制**：大奖章封顶 ~100 亿美元——「方法有容量」是最诚实
   的量化常识，也是我们「不提供策略」边界的终极背书
