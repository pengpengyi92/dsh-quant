# DE Shaw 开源 repo 专刊

DE Shaw 本体的 GitHub 足迹近零，但它的公开资产以另一种形态存在：
**DESRES（DE Shaw Research）**——David Shaw 的科学家分身。

## 公开资产

| 资产 | 是什么 | 价值 |
|---|---|---|
| DESRES 论文 | 分子动力学/计算化学顶级论文 | 计算科学的硬核输出 |
| Anton 超级计算机 | 自研专用芯片（非开源，但有公开论文）| 把「专用硬件」思路做到极致 |
| 人才校友 | Bezos/Overdeck/Siegel… | 公开可查的最强「产品」|

## 为什么不开源

1. **计算金融鼻祖的保密惯性**：三十年如一日的低调
2. **招聘不靠开源**：面试题库与薪资已是行业传奇
3. **开源载体在别处**：DESRES 的科研发表代替了代码开源

## 对 dsh-quant 的启发

1. **「人才产品」论**：DE Shaw 的真正产出是训练过的人——我们的
   demo/skill/历史栏目也是在「训练人」而非只出代码
2. **计算金融 → agent-native 量化**：DE Shaw 把金融变成计算问题，
   dsh-quant 把金融变成 agent 可执行问题——同一叙事的两代人
3. **科学家底色**：David Shaw 用 Anton 回到科研——「赚了钱做学问」
   提醒我们：工具是手段，研究是目的
