# SIG 开源 repo 专刊

SIG 的 GitHub 足迹为零——「母体」的沉默比它的孩子们（Jane Street 的
OCaml 生态）更彻底。

## 为什么零开源

1. **扑克文化的反面**：扑克玩家从不亮牌——SIG 把「不透露信息」
   刻进文化
2. **无人才压力**：母体自带神秘感与薪资口碑
3. **期权做市的全栈保密**：波动率曲面、报价模型、风控系统全是
   核心资产

## 公开资产是什么

| 资产 | 形态 |
|---|---|
| 人才谱系 | JS/HRT 等后代的公开档案（本栏目交叉引用）|
| 扑克/概率文化 | Yass 的扑克传说与公开牌局记录 |
| 极少访谈 | 行业会议零星的发言 |

## 对 dsh-quant 的启发

1. **「母体 vs 后代」的开源对照**：SIG 全封闭，它的孩子 JS 全开放——
   同一基因，两种战略。说明**开源姿态与创始人代际相关**，不是
   业务类型单变量决定
2. **光谱的又一锚点**：SIG 与 RenTec/Five Rings 构成「沉默三极」，
   dsh-quant 的「方法公开」在这个背景里越发稀缺——**稀缺就是
   差异化**
3. **时间线的意义**：SIG（1987）→ DE Shaw（1988）→ JS（2000）的
   谱系链是量化编年史的主线之一——见 quant-history/TIMELINE.md
