# Bridgewater 开源 repo 专刊

Bridgewater 的 GitHub 足迹为零，但它是**「思想开源」**的冠军——
策略保密，哲学全球发行。

## 公开资产

| 资产 | 是什么 | 价值 |
|---|---|---|
| 《Principles》 | Dalio 的决策算法书（全球畅销）| 「把公司管理写成系统」的完整样本 |
| 《经济机器是如何运行的》 | 30 分钟宏观科普视频 | 中文互联网最火的金融科普之一 |
| 《Big Debt Crises》 | 债务危机研究免费 PDF | 宏观研究的公开教材 |
| 致股东信 | 持续公开的宏观观点 | 市场思想的长期档案 |

## 为什么「零代码开源」

1. **策略层保密**：Pure Alpha 的信号与 All Weather 的配置权重
   是商业机密
2. **思想层开放**：Dalio 的「原则」是产品也是品牌——用思想获客，
   用系统赚钱
3. **第四种边界**：管理透明（会议录音/可信度加权）≠ 策略透明

## 对 dsh-quant 的启发

1. **原则即 agent 的 system prompt**：Dalio 把决策写成原则——
   dsh-quant 的 skill 体系（quant-research/quant-release-cycle）
   就是「量化研究的原则」的 agent 版
2. **风险平价的工具化**：All Weather = 每种经济环境等量风险——
   `quant_backtest_portfolio` 的最小实现与教学入口
3. **思想资产的复利**：《Principles》出版十年后还在给 Bridgewater
   拉新——公开内容是最长效的获客（我们栏目的同构逻辑）
