# GSA Capital 开源 repo 专刊

GSA 的 GitHub 足迹为零——伦敦式低调的又一端。无官方 org、无
公开库、无技术博客。

## 为什么零开源

1. **系统化多策略全栈保密**：统计套利的信号与执行都在封闭系统
2. **低调文化**：零公开演讲的机构，开源无从谈起
3. **无人才压力**：伦敦 quant 圈的口碑雇主，简历不愁

## 对 dsh-quant 的启发

1. **光谱的伦敦样本**：GSA 与 Squarepoint 构成「大行自营组后代」
   的低调双样本——欧洲量化的公开度整体低于美国（监管与文化的
   双重原因）
2. **「产品力 > 声量」的极端版**：GSA 证明零宣传也能做到行业
   顶级——dsh-quant 选择开源宣发是「换生态位」的主动选择，
   GSA 是「不换」的对照组
3. **本专刊的存在意义**：零 repo 也记录——光谱完整性优先
