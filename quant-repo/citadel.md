# Citadel 开源 repo 专刊

Citadel 的 GitHub 足迹**几乎为零**——没有成体系的官方开源 org，没有
SDK，没有技术博客生态。这本身就是一个值得写进专刊的「开源姿态」样本。

## 现状

- 官方公开仓库：屈指可数的小型工具，无核心系统、无框架、无教育项目
- 技术演讲：极少量；招聘以保密协议与内部训练著称
- 与 Jane Street（~90 repos）形成量化界的两极

## 为什么这是「刻意」的

1. **保密是文化**：Citadel 的竞争观是「任何公开都是信息泄漏」——
   连员工都几乎不对外演讲
2. **开源回报对他们不成立**：他们不缺候选人（薪资+品牌足够），
   不需要用开源吸引人才；而 Jane Street 需要 OCaml 生态的协作网络
3. **两种商业模式**：Jane Street 开源的是「框架层」（语言库），
   Citadel 连框架层都不给——边界比我们（dsh-quant）极端得多

## 对 dsh-quant 的启发

1. **开源姿态是战略选择，不是默认**：dsh-quant 选择「方法公开、秘密
   内部」——介于 Jane Street（框架也公开）与 Citadel（全封闭）之间，
   对个人开发者生态是最优解：我们靠开源换讨论、PR 与生态位
2. **保密与公开的边界艺术**：三家三种边界，说明边界本身就是产品设计
   ——我们的置顶 Issue #9 写的就是这件事
3. **没有 repo 也是资料**：本专刊如实记录「Citadel 无开源」，
   供研究者理解行业光谱的全貌
