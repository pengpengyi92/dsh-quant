# Squarepoint 开源 repo 专刊

Squarepoint 的 GitHub 足迹**为零**（无官方 org、无公开工具库）——
与它的企业文化一致：低调到隐身的另一极。

## 现状

- 无官方开源 repo、无技术博客、无竞赛、无平台
- 公开资料仅限：官网 About 页、Wikipedia 档案、招聘信息

## 为什么（光谱的「隐身端」）

1. **系统化多策略 = 全栈保密**：统计套利/做市/宏观量化的组合配置
   本身就是秘密
2. **无人才压力**：从大行自营组继承的团队与品牌，无需开源引流
3. **零公开成本最低**：不说话就没有合规/信息泄漏风险

## 对 dsh-quant 的启发

1. **开源光谱的完整性**：九家机构从「零开源」到「框架级开源」，
   每种姿态都是战略选择——dsh-quant 的「方法公开」在光谱上选择
   了最适合个人开发者的位置（开源换生态位）
2. **「隐身」的代价**：Squarepoint 的知名度显著低于同行——
   不开源的另一面是生态影响力为零。对 dsh-quant 而言，
   影响力（quant_oss_pulse 度量）是明确的战略资产
3. **参考对照**：本专刊的存在意义——即使零 repo，也记录「为什么零」，
   让光谱完整
