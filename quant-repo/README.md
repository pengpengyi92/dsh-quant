# quant-repo —— 量化大厂开源 repo 专刊

收录量化机构的**开源仓库**介绍：每个 repo 讲清「是什么、为什么开源、
能学到什么」。首批：**Jane Street · Optiver · Citadel**。

> 与 `quant-history/` 分开：历史讲人与事，这里讲代码与工程。
> 欢迎 PR 补充遗漏 repo 或新机构。

## 收录规则（欢迎 PR）

- 每个 repo：一句话 + 技术栈 + 能学到什么
- 只收机构官方 org 下的仓库（个人移植标注说明）
- 标注活跃度（stars/更新状态）与许可证
