# Virtu 开源 repo 专刊

Virtu 的 GitHub 足迹为零（无官方 org、无公开库）——做市系统全封闭。

## 公开资产是什么

Virtu 的「公开」不在代码，而在**披露文件**：

| 资产 | 价值 |
|---|---|
| IPO S-1（2015）| 「1238 天 1 亏」数据 + 做市商经济模型的罕见披露 |
| 历年年报/10-K | 做市收入的规模化数据（各资产类别口径）|
| 收购史（KCG/ITG）| 做市行业整合的公开案例 |

## 为什么零开源

1. **做市系统 = 策略本体**：订单簿、路由、风控全是核心竞争力
2. **上市公司合规成本**：任何代码出口都要过法务——与 Millennium
   同因不同形
3. **无人才压力**：军事化文化与稳定薪酬足够

## 对 dsh-quant 的启发

1. **披露文件也是学习材料**：S-1 里的做市经济模型（价差/成本/风控）
   是公开的行业教材——quant-history 栏目与 repo 栏目合起来读
2. **「1 天亏损」的工程含义**：极端纪律的做市 = 我们 `quant_execute_sim`
   想模拟的「统计确定性的生意」
3. **光谱再确认**：做市系（Virtu/Citadel/HRT）普遍零开源，研究系
   （Two Sigma/JS）偏开放——**业务类型决定开源姿态**
