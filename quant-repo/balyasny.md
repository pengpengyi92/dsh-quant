# Balyasny 开源 repo 专刊

Balyasny 的 GitHub 足迹为零——平台化多策略的保密叠加。

## 为什么零开源

1. **多经理平台全栈保密**：数十个团队各自保密，中央风控系统更是
   核心资产
2. **无人才压力**：平台制 + 薪酬足够吸引人
3. **合规成本**：芝加哥低调派与 Citadel 同因

## 对 dsh-quant 的启发

1. **平台制的共性**：Millennium/Balyasny/Point72 三家平台制全零
   开源——「分散策略 + 集中风控」的组织里，风控代码是最不该
   公开的部分（dsh-risk 域给个人开发者的价值正源于此）
2. **光谱的稳固**：芝加哥三巨头（Citadel/Balyasny/Millennium）
   构成「零开源地带」——dsh-quant 的开源选择在光谱上越发清晰
