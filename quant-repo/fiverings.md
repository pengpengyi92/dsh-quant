# Five Rings 开源 repo 专刊

Five Rings 的 GitHub 足迹为零——神秘精英自营的完全保密。

## 为什么零开源

1. **自营 + 小团队**：没有客户、没有招聘压力、没有品牌需求
2. **神秘感是文化**：连面试题目都靠口耳相传——保密到骨子里
3. **无任何公开动机**：开源的四类动机（招聘/获客/生态/合规）
   它一个都不需要

## 对 dsh-quant 的启发

1. **光谱的完整性**：Five Rings 与 RenTec 构成「神秘双极」——
   它们的存在让「开源是选择而非默认」成为铁律
2. **谜题文化 vs 开源文化**：Five Rings 用「不公开的谜题」营销，
   dsh-quant 用「公开的 demo/手算测试」营销——两种人才漏斗的
   对照实验
3. **本专刊的价值**：零 repo 也记录——每一家的「为什么零」都是
   战略教材
