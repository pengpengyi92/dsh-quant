# XTX Markets 开源 repo 专刊

XTX 的 GitHub 足迹极少（xtxmarkets org 有零星工具库）——纯自动化
做市的系统全封闭，但「极少」不等于「为零」。

## 现状

- xtxmarkets org：少量工程工具（非核心系统）
- 无 SDK、无竞赛、无技术博客生态
- 公开资产主要是**财务披露**（英国 Companies House）——「人均
  产值之王」的数据全在那里

## 对 dsh-quant 的启发

1. **自动化公司的开源悖论**：XTX 的竞争力是「代码即公司」，
   所以最不可能开源——与 RenTec 同逻辑、不同规模
2. **披露文件型公开**：与 Virtu 一样，XTX 的「公开」在监管
   文件里——研究公开光谱时，财报也是 repo
3. **200 人神话的工程注脚**：如果哪天 XTX 开源工具，那就是
   「自动化基础设施可以共享」的又一证据——目前先记录为零星
