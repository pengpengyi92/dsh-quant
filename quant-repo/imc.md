# IMC 开源 repo 专刊

IMC 的开源 = **竞赛 SDK**：imc-prosperity org 发布年度挑战赛的
starter kit，社区生态自动生长。

## 核心资产

| repo/资产 | 是什么 | 价值 |
|---|---|---|
| imc-prosperity 官方 starter kits | 年度竞赛的模拟交易所 + 交易框架 | 做市游戏的新一代官方 SDK |
| 社区回测器（如 [jmerle/imc-prosperity-2-backtester](https://github.com/jmerle/imc-prosperity-2-backtester)）| 离线回测器 | 生态自生长的证明 |
| 复盘/教程（如 Leo-Hawking 的 Prosperity 4 Review）| 深度策略复盘 | 「竞赛即教育」的完整闭环 |

## 对 dsh-quant 的启发

1. **竞赛 SDK 是最佳教学开源**：IMC 与 Optiver 用同一招（竞赛+
   开源框架）圈住全球学生——dsh-quant 的 demo/基金模拟游戏化
   同源
2. **社区生态的自组织**：官方只给 starter，回测器/复盘/AI 助手
   全是社区产物——「给最小框架，生态自己长」
3. **做市教育的两代**：Optiver RTG（2020-23）→ IMC Prosperity
   （2023+）——做市竞赛在迭代，我们的 PET 执行域可以持续对齐
   新一代题面
