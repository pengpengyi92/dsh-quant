# Wind 万得 —— 中国金融数据的"Bloomberg 对应物"

## 起源与定位

万得（Wind Information）1994 年创立于上海，以中国金融数据终端起家，
逐步成为**中国机构市场覆盖率最高的金融数据终端**——券商、基金、银行、
高校的标配，"在中国做金融研究，绕不开 Wind"。

## 数据覆盖（概览，具体条款以官方为准）

- 中国股/债/基金/宏观/商品/外汇全谱系，历史深度是核心壁垒
- 中国债券市场数据是公认最强项之一（银行间/交易所/信用债谱系）
- 数据接口（Wind API / 量化接口）广泛被量化私募用于中台（PDAT 同构场景）

## 终端体验

- 传统 Wind 终端是**类 TUI 的键盘流产品**（命令式交互、功能键、密集表格），
  近年补充图形化客户端与 Excel 插件
- 学习成本高、专业密度高——与 Bloomberg 同源的产品哲学

## 商业模式

- 年费数万人民币/台（机构报价分档，**以官方报价为准，待考证**）
- 高校采购与机构渗透形成事实标准；中国市场定价权集中

## 对我们的意义

1. **中文金融数据的事实标准**——dsh-quant 的 `fetchKlines` 已接入 sina/tencent
   免费源，但机构级深度数据仍需 Wind 类上游；这是我们数据边界设计时
   必须直面的现实
2. 中国量化产业链上游研究的最佳样本：数据源 → 私募中台 → 策略
3. 观察点：Wind 的 API/量化接口生态，就是"卖铲子"生意的中国版本
