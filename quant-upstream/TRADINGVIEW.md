# TradingView —— 图表即产品

## 历史（起源 → 现状）

- **2011** Stan Bokov、Denis Globa、Constantin Ivanov 创立（纽约/伦敦，
  俄裔创业者团队）——从 HTML5 图表组件起家
- **2013 前后** Pine Script 策略语言发布（**具体年份待考证**）——
  让普通用户用脚本写指标与策略，平民化量化语言
- **2015 后** 成长为全球最大零售交易图表与社交平台，月活数千万级
  （公开报道区间，**待考证**）
- **2022** 融资估值约 $30 亿美元级（公开报道，**待考证**）
- **至今** 订阅制（免费层 + Pro/Premium），全球交易所行情接入，
  社区策略分享生态

## 定位与数据

- 定位：**零售交易者的"Bloomberg"**——图表是核心产品，社区是护城河
- 数据：全球主流交易所零售级行情（延迟/实时分档），机构级深度数据
  并非主业

## 产品哲学

- "图表即产品"：把可视化做到极致，然后一切（脚本、社交、数据）围绕图表生长
- Pine Script 的启示：**给用户一门 DSL，用户自己长出一个生态**

## 对我们的意义（特殊）

1. **dsh-quant-ui 用的 lightweight-charts 就是 TradingView 开源的图表库**——
   我们的可视化直接站在上游的肩上，这是"用上游开源、做中游产品"的
   最佳案例
2. Pine Script 路线 = "让策略可表达"；我们的路线 = "让研究可执行"——
   两条平民化道路的对照研究
3. 零售上游 vs 机构上游的定价分层：同一家公司，图表免费、数据收费、
   订阅分档——上游的漏斗式变现教科书
