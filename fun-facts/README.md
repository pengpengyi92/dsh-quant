## 投稿规范

1. 文件名：`NNN-slug.md`（三位序号）
2. 结构：`## The fact`（事实）+ `## Why this matters to us`（与我们项目的关系）
3. 事实要有出处意识——不确定的标注"待考证"，不编造
4. 有趣的 > 正确的？不。**正确且有趣的** 才配进这里。

## 原则

> Fun facts 是这个仓库的"人文层"：量化不只是因子和回测，也是人和故事。
> 每一个 fun fact 都应该能让我们更理解"为什么我们做这些事"。
