# ECB — Early Career Benchmark

**ECB = Early Career Benchmark.**

ECB 用一家公司如何识别、筛选、培养、轮岗、定岗和保留早期职业人才，反向推断其真实的 **organizational orientation / culture / talent model**。

它与 JMatrix 互补：

- **JMatrix**：Job × People，回答“这个岗位是什么、谁在做、怎么切入”。
- **ECB**：Early Career Pipeline，回答“这家公司从最早期开始想培养什么样的人，以及它认为未来最重要的能力是什么”。

## Benchmark dimensions

| Dimension | Questions |
|---|---|
| Discovery | 公司多早开始识别人才？竞赛 / campus / insight / internship？ |
| Entry | Internship / Graduate / MT / Apprenticeship 有哪些入口？ |
| Selection signal | Math / coding / leadership / communication / markets / sales / domain knowledge？ |
| Role topology | 一开始就进入 narrow role，还是先理解组织再分化？ |
| Training architecture | Classroom / OJT / mentor / buddy / rotation / project？ |
| Specialisation timing | 多早进入明确 job family？ |
| Ownership timing | 多早承担 production / client / PnL / system ownership？ |
| Mobility | Team / function / city / country / market 的移动机制？ |
| Conversion | Internship → full-time → leadership / SME 是否形成显式 funnel？ |
| Terminal model | 公司最终想培养 researcher / trader / engineer / banker / PM / manager / operator 中的哪一种？ |

## Core interpretation rule

> **Look at what a firm invests in before a young employee has produced much output.  
> That investment reveals what the firm believes will compound.**

ECB 不是“哪个公司更好”的排行，而是一个 **company-culture reverse-engineering protocol**。

## Comparative archetypes

当前可用于横向比较的 archetype：

- Jane Street — problem solving / ownership / narrow-role excellence
- Point72 — investment apprenticeship / PM ecosystem
- Optiver — market making / trading-engineering
- QRT — systematic research / engineering
- Two Sigma — research + technology
- Tencent — product-tech-business
- Ping An Bank — commercial banking / organization-map / client-operation lens
- BOCHK — institutional banking / rotation / cross-border leadership
- HSBC — function-first / global-platform / specialist development

### Bank ECB spectrum

- **Ping An Bank** — Organization-first × Commercial-first → Commercial Banking Operator School
- **BOCHK** — Institution-first × Rotation-first × Cross-border → Cross-border Institutional Banker School
- **HSBC** — Function-first × Global-platform-first → Global Specialist Banker School
