# 0.17.0 — dsh-community 开源生态域（自我造血工具）

## 背景
星标增长行动之后：打造自己的开源生态影响力工具——dsh-quant 的第六个域
`dsh-community`（开源生态域）。内部五队没有对应物，是开源侧独有的资产：
开源侧用开源的工具度量自己的生态影响力（eat your own dog food）。

## 新增
- `quant_repo_stats`：GitHub 仓库生态数据（星标/复刻/议题/PR/topics/最新 release），
  公共 API 无需凭据；有 GITHUB_TOKEN 环境变量时自动走认证通道（60/h → 5000/h）
- `quant_npm_stats`：npm 包生态数据（最新版/周下载/月下载）
- `quant_oss_pulse`：0-100 影响力评分 + A/B/C/D 等级 + 具体行动建议
  - stars 基数 20% / npm 周下载 15% / 星标增速 25% / 社区健康 20% / 发布新鲜度 20%
  - 缺省项中性 50（不惩罚信息不足），纯函数、全部可手算
- 13 个手算单元用例（社区域），单元总数 100 → 113，工具 34 → 37
- GITHUB_TOKEN 支持（实测：匿名 API 60/h 被耗尽 → 认证通道恢复）

## 自测结果（吃自己的狗粮）
verify 实测 dsh-quant 自己：stars 3 | open issues 7 | 7d downloads 0
→ pulse 40 / C：积压 issue 偏多 + 星标基数小 + npm 下载低
→ 工具给出的建议就是接下来的行动清单

## 工程
- 域结构：src/dsh-community/{github,npm,pulse}.ts + README
- 测试：113 单元 + 4 Loader + verify 实时全绿
- 发布：v0.17.0 → CI + release 自动 npm 发布

## 教训
- GitHub 匿名 API 60 req/h/IP 是真实瓶颈 → GITHUB_TOKEN 可选升级通道（与行情三所
  容错链同一哲学：不依赖单一脆弱路径）
