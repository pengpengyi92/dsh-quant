# 0.19.0 — PCPT 补完版（ML/DL 架构知识 + 框架 + demo）

## 背景
0.18.0 之后审计 PCPT 公开承诺（「提供 demo + ML/DL 知识 + 一些框架」）：
框架种子（walk-forward）已有，但架构知识、独立模型工具、ML demo 全部空白。
dsh-ml README 甚至写着「ML/DL 为未来扩展方向」——本版兑现承诺。

## 新增
- `quant_linear_model`：独立 OLS/Ridge fit/predict（λ 只惩罚特征权重），
  训练 R2 + 可选样本外 test R2/IC（43 工具）
- `docs/ML_GUIDE.md`：量化 ML/DL 架构知识地图
  - 研究管线架构（数据→特征→标签→模型→验证→执行，每环的泄漏点）
  - 模型阶梯（线性→逻辑→树→DL→RL：能力/风险/可解释性权衡表）
  - 样本外验证金标准（walk-forward、禁随机 K 折、Purged K-Fold、Deflated Sharpe）
  - 过拟合诊断清单（参数平面平滑性、特征/样本比 30:1、IC 衰减形状、换手成本）
  - RL 问题形式化（状态/动作/奖励/环境/评估训练分离；生产 RL 难点归内部）
- `demos/ml-workflow.ts`：可执行 ML demo——真实 BTC → 动量+反转特征 →
  中性化 → 线性模型 70/30 切分 → walk-forward → 教育性结论
  （实测：train R2 0.004 / test IC 0.027 / walk-forward OOS IC -0.167——
  诚实展示弱信号，正是 demo 的教育意义）
- dsh-ml/README 重写：从「ML/DL 为未来扩展方向」升级为「ML 框架就位 +
  DL/RL 知识层」，链接 ML_GUIDE 与 demo

## 质量
- 单元测试 149 → 156（+7 线性模型手算：完美拟合/Ridge 收缩/多特征/评估/前置条件）
- loader 4、实时验证含线性模型（真实 BTC 动量特征 fit/predict/test IC 0.1564）

## 教训
- demo 的标签对齐比模型本身容易错：features[t] 对应 close[12+t] 时，
  预测目标只能是 ret[13+t]，上界 t ≤ n-2（第一次跑出 NaN test IC 即此因）
