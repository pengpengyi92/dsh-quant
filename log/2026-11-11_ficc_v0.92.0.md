## Change

structured provenance and generated Markdown. General Discussion #151 hosts
replies and per-project community ratings; open Issue #152 and the FICC Issue

reference is isolated. Canonical repo transfers and legacy-status conflicts
are recorded. Private research and trading materials were not copied.

@klauschenshu-arch, @ziladan and @aprsn. Historical source/tag provenance remains.

## Trade-off → Next Action

Source review is a discovery aid, not numerical validation or data rights.
Keep GitHub Release and npm installability separate. Weekly maintenance uses
Issue → Discussion → reviewed PR → merge → credit; an Issue itself is closed
with a PR receipt and cannot be merged. No unattended merge is configured.
