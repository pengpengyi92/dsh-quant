## 三、全球对比（含中国 · 四城 vs 国内）

| 口径 | 估算人数 |
|---|---|
| 纽约 | ~10,000-15,000 |
| 伦敦 | ~8,000-12,000 |
| 香港 | ~3,500-6,000 |
| 新加坡 | ~3,000-5,000 |
| **四城合计** | **~25,000-38,000** |
| 中国全国（广义） | ~30,000-50,000 |
| **全球估算（四城 + 中国 + 其他）** | **~80,000-120,000** |

**关键发现**：
1. **纽约+伦敦 ≈ 中国全国**：欧美双核（~18,000-27,000）与
   中国全国（~30,000-50,000）同量级——**中国量化从业者总量
   已不输欧美双核，但分散度更高**。
2. **单厂规模差距**：Millennium/Point72 单厂 2,000-4,000 人
   vs 幻方/九坤 200-500 人——**欧美头部单厂是中国头部的
   5-10 倍**；中国靠「厂数多」追平总量。
3. **人均产值对照**：XTX 200 人 / £12.8 亿利润——**人数最少
   的厂反而人均最高**（人均之王）；中国头部人均产值与之
   差距主要在 AUM 而非人数。
4. **四城密度**：四城 ~104 家机构承载 ~25,000-38,000 人——
   **平均每家 ~240-370 人**（含大厂拉高）；中国量化私募
   平均每家 ~15-30 人——**欧美机构密度是中国的 10 倍**。

## 四、对 dsh-quant 的启示

1. **全球 ~80,000-120,000 量化从业者是生态基数**：即使 1%
   使用 dsh-quant，也是 800-1,200 个 agent 会话——「方法
   公开」路线的市场足够大。
2. **中小团队是全球共性**：欧美也有大量 10-50 人的中小
   量化（卫星城/新贵），它们和中国的 15,000-25,000 中小
   团队一样缺工具——**dsh-quant 服务的是「长尾」不是头部**。
3. **四城 = 渠道知识库的需求侧**：伦敦/纽约/新加坡/香港的
   机构分布就是 dsh-quant 三市场行情（加密/A股/全球）的
   用户地图。
