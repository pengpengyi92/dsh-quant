## 七、结构分析（新加坡作为枢纽的五条规律 · 对照香港）

| 维度 | 香港 | 新加坡 |
|---|---|---|
| 定位 | 中国敞口 + 传统牌照 | **加密 + 家办 + 东南亚** |
| 数量 | ~26 家 | ~20 家 |
| 增速 | 2025-26 回升 | **2020s 持续高增** |
| 总部样本 | QRT + GSR | **Wintermute Asia + GSR 双点 + Modular（本土）** |
| 做市浓度 | Jane Street 为主 | **Optiver + Jane Street + HRT 三强** |
| 加密浓度 | GSR + Alameda（历史）| **Wintermute 总部 + GSR + 监管友好** |
| 财富侧 | 传统私行 | **家办（一年 +600 间，跑赢香港）** |
| 人才流 | 外资进中国 | **新→港反向流（Modular 2025）** |

**结论：香港是「进中国的桥头堡」，新加坡是「加密 + 财富 + 东南亚
的枢纽」——「亚洲双子」各有分工，2020s 新加坡的增速反超香港，
靠的是加密监管 + 家办政策 + 做市浓度三张牌。**

## 八、对 dsh-quant 的启示

1. **政策洼地 = 生态位**：新加坡用 MAS 牌照 + 加密友好监管做出
   差异化——dsh-quant 的「方法公开 + 插件生态」同样是「政策
   洼地」：**没有牌照，也能做全球量化的基础设施**。
2. **家办 = 量化需求侧**：新加坡家办暴增（一年 +600 间）意味
   大量「钱找策略」——dsh-quant 的 `quant_fund`（模拟基金）+
   `quant_report` 就是「给家办讲清楚策略」的工具链。
3. **双城分工是行业地图**：香港=中国，新加坡=东南亚+加密——
   dsh-quant 的渠道知识库（binance/okx/bybit 加密 + sina/tencent
   A股 + yahoo 全球）正好覆盖「双子」对应的市场。
4. **反向流动是信号**：Modular（新→港）证明新加坡已能「输出」
   机构——**枢纽的地位不只看吸引，还看出产**。
