# Bridgewater —— 宏观之王与「原则」帝国

## 起源（1975）

1975 年由 Ray Dalio 在纽约公寓创立，后迁至康涅狄格州 Westport。
从商品咨询（向麦当劳卖鸡肉对冲建议的段子是真的）做到**全球最大
对冲基金**——宏观策略（Pure Alpha）+ 风险平价（All Weather）。

## 里程碑

- AUM 峰值 ~1680 亿美元（2022 前后）——对冲基金史上最大
- **All Weather（全天候）**：把风险平价（risk parity）产品化——
  「任何经济环境都能活」的组合哲学
- 2008 金融危机前 Dalio 公开预警（《经济机器是如何运行的》视频
  是中文互联网最火的金融科普之一）
- 2017 Dalio 卸任 CEO；2022 正式交棒管理层
- 2020s 规模收缩与业绩波动（宏观基金共同困境），但品牌仍是
  行业图腾

## 文化：极端透明

- **Radical Transparency**：会议录音全员可听、可信度加权决策
  （Believability-weighted decision making）——把公司管理做成
  工程系统
- 《Principles》（原则）全球畅销：把个人与组织的决策算法写成书
- 「想法精英制」（Idea Meritocracy）：最好的想法赢，不看职级

## 对量化 R&D 的启示

1. **风险平价思想**：All Weather 的本质是「让每种经济环境贡献
   等量风险」——组合层工具（`quant_backtest_portfolio`/risk 域）
   的最小实现
2. **原则即系统**：Dalio 把决策写成算法——agent 时代的「原则」
   就是 system prompt + skill 层（dsh-quant 的 skill 体系同构）
3. **透明与业绩的权衡**：Bridgewater 的透明是「管理透明」而非
   「策略开源」——公开哲学、保密持仓，第四种边界形态
