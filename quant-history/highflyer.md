# 幻方量化（High-Flyer）—— DeepSeek 的起源

## 起源（2015）

2015 年成立于杭州，创始人梁文锋（Liang Wenfeng）与徐进等。幻方
是中国量化私募的旗帜之一——管理规模一度超千亿（2021 巅峰期），
更是 **DeepSeek 的母公司**：中国量化的最大文化输出。

## 演进路线

```
2015 杭州成立，机器学习驱动的量化选股
  → 2017 全面 AI 化（自建萤火系列超算——量化界的算力军备竞赛）
  → 2019 幻方 AI（DeepSeek 前身）
  → 2021 管理规模千亿级，中国量化「千亿集结」时代
  → 2023 DeepSeek 成立，量化业务让位于 AGI
  → 2025 DeepSeek 震动全球 AI 格局
```

## DeepSeek 的开源神话

- deepseek-ai org：V3/R1 等模型开源——**量化公司成了全球 AI 开源
  旗帜**，R1 让「中国开源模型」第一次站上世界之巅
- 梁文锋从量化走向 AGI：算力、工程、研究文化的全面迁移

## 对量化 R&D 的启示

1. **量化的终点可能是 AGI**：幻方把量化训练出的「算力 + 工程 +
   研究」三件套平移到了大模型——量化是 AI 的黄埔军校
2. **超算军备**：萤火超算证明了「算力即 alpha」的极端版本
3. **dsh 与 dsh-quant 的血缘**：DeepSeek Harness 出自 DeepSeek，
   DeepSeek 出自幻方——dsh-quant 的「母体谱系」在中国篇完成了
   闭环：**幻方 → DeepSeek → dsh → dsh-quant** 🐳
