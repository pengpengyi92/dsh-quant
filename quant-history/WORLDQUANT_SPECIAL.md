# 专题报告：WorldQuant 超级深挖专刊（WORLDQUANT SPECIAL · Alpha 工厂）

> 档案（worldquant.md）的深挖版。核心问题：**为什么 WorldQuant
> 是量化界的「Alpha 工厂」**？——把因子研发从「少数天才」变成
> 「全球流水线」，用平台而非个人生产 alpha，以及 101 Formulaic
> Alphas 如何成为整个行业的公开教科书。

WorldQuant 是 **「工厂之王」**——不靠任何单一个人或单个
alpha，靠的是「把 alpha 生产工业化」这条路线。

## 二、起源（2007 · Millennium 系的工业革命）

- **Igor Tulchinsky**：前 Millennium 交易员/研究员——**从
  Millennium 的 pod 模式里长出来的反叛者**：不搞少数 PM，
  搞「人人可产 alpha」的平台
- 名字：WorldQuant = **「世界的量化」**——野心写在名字里
  （与 XTX「名字无意义」、SIG「河名」、JS「街名」形成命名
  学四极）
- 2007 年金融危机前夜成立——**在别人恐惧时建工厂**

## 四、Alpha 工厂的流水线（核心秘密）

```
全球研究员网络（顾问/兼职/竞赛选手）
  → BRAIN / WebSim（表达式 → 仿真 → 回测 → 提交）
  → 合规 alpha 入库（数据校验 + 过拟合检查）
  → 组合层配置（Millennium Advisors 等载体）
  → 实盘（不公开的组合与参数）
```

### 1. 平台即护城河（不是 alpha 是流水线）
WorldQuant 的护城河不是某个 alpha，而是**生产 alpha 的平台**：
WebSim 让「写表达式 → 回测 → 提交」变成标准动作——**把天才
的直觉流程化**。

### 2. 众包研究员网络（全球人才杠杆）
BRAIN 顾问不拿工资拿「分润」——**零底薪的全球分布式研究
军团**：数以万计的研究员兼职为 WorldQuant 生产 alpha，公司
只付被采纳的成果。人力成本模型行业独一份。

### 3. 规模即筛选（1 亿个 alpha 里挑）
2018 年已模拟 ~1 亿个 alpha——**数量本身就是质量**：海量
候选 → 严格入库检验 → 组合层精选。和 Citadel 的「全栈自研」
相反，WorldQuant 是「众包海选」。

### 4. 竞赛即招聘（IQC 的人才漏斗）
IQC 国际量化锦标赛：全球赛区 → 决赛 → 奖金 + 全职/顾问
offer——**招聘变成了比赛**，比赛变成了市场推广。全球
Alphathon 进一步把竞赛工业化。

### 5. AI 加速研究（2025 的新军备）
Forbes 2025：Tulchinsky 用 ChatGPT 式 LLM 加速模型研究——
「生成 → 仿真 → 入库」的每一环都被 LLM 提速——工厂升级为
**智能工厂**。

## 五、101 Formulaic Alphas：公开教科书的分量

- **Kakushadze 2016**（Journal of Portfolio Management）：把
  101 个量价 alpha 写成公式论文——**「可复现的因子研究」的
  行业标准**
- 为什么公开？——**alpha 的半衰期**：公开的因子会衰减，但
  「研究范式」不会。公开 101 个旧 alpha，换来的是一代研究
  员用 WorldQuant 的思维框架做事
- 对行业的影响：全球 quant 入门读物；无数因子库的验收集；
  dsh-quant 的 `quant_factor_evaluate` 可拿它当公开基准
- **边界哲学样本**：「工具与方法公开，组合与参数内部」——
  WorldQuant 是「方法开源、资产闭源」的世界级先行者

## 七、与 SIG/Citadel/XTX 的四路对照（母体/工厂/规模/人均）

| 维度 | SIG | WorldQuant | Citadel | XTX |
|---|---|---|---|---|
| 定位 | 母体 | **工厂** | 规模之王 | 人均之王 |
| 起源 | 1987 扑克朋友 | 2007 Millennium 系 | 1990 宿舍套利 | 2015 数学家 |
| 核心机制 | 概率操作系统 | **众包流水线** | 双引擎 | 零交易员 |
| 人才策略 | 面试筛天赋 | **竞赛+顾问海选** | 精英竞技场 | 数学俱乐部 |
| 命名 | 河名 | 世界的量化 | 城堡 | 无意义 |

**结论：量化五条路径——做对决策（SIG）、建对工厂
（WorldQuant）、做大规模（Citadel）、做少人数（XTX）、
做对类型（JS）。WorldQuant 证明：alpha 可以是工业品。**

## 八、对 dsh-quant 的启示

1. **因子研发可以流水线化**：WebSim 的「写因子 → 仿真 →
   入库 → 组合」正是 dsh-quant 的 `quant_factor_evaluate` +
   `quant_walk_forward` 的开源版——**把 WorldQuant 的流水线
   哲学做成免费工具**
2. **公开基准的价值**：101 Alphas 证明「公开旧方法能换行业
   影响力」——dsh-quant 的「方法公开、秘密内部」在同一光谱
3. **竞赛即生态**：IQC 把招聘/营销/研究三合一——dsh-quant
   的「一切皆插件 + PR 欢迎」是竞赛模式的慢速版
4. **AI 加速研究是下一站**：Tulchinsky 用 LLM 提速研究——
   dsh-quant 的 AI-native 定位（46 工具 + subagent 并行研究）
   正是「智能工厂」的另一种实现
