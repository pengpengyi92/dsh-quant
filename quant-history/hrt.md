# Hudson River Trading —— 纯算法自营的工程师王国

## 起源（2002）

2002 年成立于纽约，创始核心 Jason Carroll、Brad Scheler 等来自 MIT 的
算法交易圈。名字来自哈德逊河——纽约算法交易的图腾之一。从第一天起，
HRT 就是**纯算法**：没有主观交易员，只有算法与工程师。

## 演进路线

```
2002 纽约自营算法交易起家
  → 2010s 全球扩张（伦敦/新加坡/上海/孟买/都柏林…）
  → 做市 + 自营并行，覆盖股票/期货/期权/固收/加密
  → 2020s 全球顶级算法做市商（与 JS/Citadel Sec/Virtu 同级）
```

## 文化

- **算法即产品**：公司没有「策略」与「技术」之分——代码就是策略
- **研究驱动的招聘**：以算法与数学谜题面试著称（与 Jane Street 齐名的
  难度），招聘页常年「Algo Developer」开放
- **自营资金自由**：不管理外部客户钱，没有募资压力，专注长期研究
- 公开度低：极少演讲、极少论文、开源近零（谜题文化反而是它的
  公开资产——面试题在互联网上流传成梗）

## 对量化 R&D 的启示

1. **算法优先的组织**：把「研究」和「工程」合成一个角色（Algo Dev）——
   dsh-quant 的定位「quant 研究工程」同构
2. **谜题即招聘漏斗**：HRT 用流传的面试题做品牌——PMMLAB 的竞赛
   /dsh-quant 的 demo 是同一逻辑
3. **自营的自由**：没有客户资金 = 没有赎回压力 = 可以承受长周期研究
