# quant-history —— 量化大厂历史栏目

收录做市商与量化机构的**历史档案**：起源、关键人物、策略演进、文化、
里程碑与数据。首批三家：**Citadel · Optiver · Jane Street**。

> 定位：方法与历史的公开学习材料（dsh-quant 只讲公开事实与可验证数据；
> 内部策略与结论不在此列）。每个档案附「对量化 R&D 的启示」一节。
