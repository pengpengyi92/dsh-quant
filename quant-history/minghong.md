# 明汯投资（Minghong）—— Millennium 系的中国分支

## 起源（2014）

2014 年成立于上海，创始人裘慧明——**前 Millennium 背景**（曾在
Millennium 与 HAP 等美国机构工作）。明汯是中国量化私募头部
（百亿级），股票量化为主。

## 谱系意义

明汯是「五大母体」之一 **Millennium 的血脉在中国开枝散叶**的
代表——pod 制风控与多策略基因的中国移植。谱系树从纽约长到上海：

```
Millennium（1989 纽约）
  ├── ExodusPoint（2018，美国）
  ├── WorldQuant（2007，全球平台）
  └── 明汯（2014，中国）——基因的跨洋传播
```

## 业务与文化

- 指数增强、市场中性、CTA 多线
- 上海总部；中国量化「北幻方、南明汯」的说法一度流行
- 机构化治理 + 平台化投研

## 对量化 R&D 的启示

1. **母体基因跨洋**：明汯证明「组织知识」可以跨国移植——
   LINEAGE 报告的谱系线新增中国支线
2. **中国量化的机构化**：海外背景创始人带回的合规与风控文化，
   是中国量化从草莽到机构的关键推手
3. **A股量化的特殊性**：涨跌停、T+1、融券限制——海外方法
   必须本土化（dsh-quant 的 A股渠道/复权设计同源）
