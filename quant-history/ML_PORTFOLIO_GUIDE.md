## 一、ML/DL 的常见量化应用（四大类）

### 1.1 收益预测（信号生成）⭐ 最主流
```text
输入：因子/价量/另类数据
模型：线性回归 → GBDT（LightGBM）→ 深度学习（LSTM/Transformer）
输出：预测收益 → 排序/打分 → 选股
```
- **GBDT 是主力**（LightGBM/XGBoost）：非线性 + 特征交互，性价比最高
- **深度学习**（Transformer 等）：时序依赖 + 端到端，但需要大样本
- **我们**：dsh-quant linear（线性基线）+ PMMT 波动率预测

### 1.2 因子挖掘（Alpha 发现）
- **GBDT 特征重要性**：自动发现因子
- **自编码器**：无监督因子（压缩特征）
- **遗传规划（GP）**：组合表达式（WorldQuant 式 alpha 挖掘）
- **深度学习因子**：端到端从数据到因子

### 1.3 风险模型（协方差估计）
- **收缩估计**（Ledoit-Wolf）：小样本稳健协方差
- **机器学习协方差**：非线性风险结构
- **因子风险模型**（Barra 式）+ ML 增强

### 1.4 执行优化（交易成本）
- **滑点预测**：订单流 → 冲击成本模型
- **最优执行**：VWAP/TWAP + RL（强化学习做执行）
- **做市**：ML 预测短期波动 → 报价（PMMT 波动率做市！）

## 二、ML/DL 应用的关键（诚实警示）

| 陷阱 | 说明 | 防法 |
|---|---|---|
| **过拟合** | ML 尤其容易（参数多）| walk-forward · purged CV · Deflated Sharpe |
| **未来函数** | 特征用了未来 | 严格时序（PIT 数据）|
| **信噪比低** | 金融信号弱（IC 0.05 已很好）| 降低预期 · 多因子合成 |
| **非平稳** | 市场结构会变 | regime 检测 · 滚动重训 |
| **成本敏感** | 模型预测好但换手高 | 换手正则化 · 组合优化里惩罚 |

**黄金法则**：ML 在量化不是"魔法"——是"更好的非线性工具"，必须配严格的验证
（呼应 #120 回测详解 + #101 防过拟合四件套）。

## 三、组合优化环节（信号 → 仓位）⭐ 核心

### 3.1 为什么需要组合优化
```text
有了信号（预测收益）→ 直接买最高？不行——
1. 风险没控制（行业/风格集中）
2. 换手没控制（成本爆炸）
3. 容量没考虑
→ 组合优化：在约束下找最优权重
```

### 3.2 组合优化的数学
```text
最大化：预期收益 - λ·风险 - 换手惩罚
约束：权重和=1 · 行业中性 · 风格约束 · 单票上限
风险：w'Σw（协方差）
```
- **均值-方差（Markowitz）**：经典框架
- **风险平价**：等风险贡献
- **最大分散化**：最分散权重
- **Barra 优化**：因子暴露约束（呼应 #116）

### 3.3 组合优化 vs 打分法（两种构建方式）
| 方式 | 思路 | 优点 | 缺点 |
|---|---|---|---|
| **打分法** | 因子加权打分 → 取前 N | 简单透明 | 风险不受控 |
| **组合优化** ⭐ | 目标函数+约束 | 风险/换手受控 | 复杂 · 参数多 |

**实操**：先打分初筛 → 组合优化定权（两者结合）

### 3.4 再平衡（Rebalance）⭐ 常被忽视
```text
调仓频率（日/周/月）· 换手控制（只调到阈值外）· 成本权衡
```
- **再平衡太少**：权重漂移（偏离目标）
- **再平衡太勤**：成本吃掉收益
- **dsh-quant rebalance**：已实现再平衡逻辑

## 四、端到端流程（ML + 组合优化的完整管线）

```text
数据（PDAT）
  → 因子（quant_factor：IC/ICIR 验证）
  → 预测（ML：linear/GBDT/DL → 预期收益）
  → 组合优化（portfolioOptimize：风险约束 + 换手惩罚）
  → 再平衡（rebalance：调仓）
  → 回测（layered/backtest：验证）
  → 实盘（PET 执行）
```
