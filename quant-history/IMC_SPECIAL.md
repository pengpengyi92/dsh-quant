## 一、名字学：IMC 的全名

**International Marketmakers Combination（国际做市商组合）**——
1989 年两个荷兰期权做市商合并后的直白命名。与 Optiver（期权
做市商的荷兰语音译）并称「荷兰做市双雄」，两家名字都直接写在
脸上：一个说「我是做市商」，一个说「我是期权做市商」。

## 二、起源（1989）

- 1989 年成立于**阿姆斯特丹**，联合创始人 **Rob Defares**（长期
  CEO，Forbes 人物榜在册）
- 起点：阿姆斯特丹期权交易所（欧洲第一家期权交易所，1978 年
  开市）的场内做市——「交易所催生做市商」的又一实证
- 三十余年**零外部融资、纯自营做市**——与 DRW/CTC 同属
  「不上市、不募资」的老钱路线

## 三、历史时间线

| 时间 | 事件 |
|---|---|
| 1989 | 阿姆斯特丹成立，期权做市起家 |
| 1990s | 欧洲扩张：伦敦、其他欧陆交易所做市 |
| 2000s | 跨洋：芝加哥（美股期权）、悉尼（亚太第一站） |
| 2010s | 亚洲扩张：香港、孟买；伦敦设欧洲第二总部 |
| 2016-08 | 【事件】**证监会调查荷兰高频交易机构 IMC**（中国股指期货高频交易问询——港媒/澎湃报道）——外资 HFT 在中国的监管摩擦样本 |
| 2021-2025 | **Prosperity 竞赛 1→4 届**——全球 STEM 学生交易挑战赛成为招聘名片 |

## 五、文化与 fun facts

1. **Prosperity 四届封神**：2021 起每年一届的全球交易挑战赛
   （P4 主题「cosmic proportions」）——参赛者在 GitHub 公开
   提交方案（top 队伍带复盘 writeup）——**做市商里最会办竞赛的**
2. **创始人竟是艺术收藏家**：Rob Defares 入选 Artnews「Top 200
   收藏家」——量化老钱的另一面
3. **全自动做市文化**：早期场内人工做市 → 全面自动化——与
   Optiver 的「交易员+工程师」混合文化形成对照
4. **2016 年被调查梗**：外资 HFT 机构在 A 股股指期货的「速度
   争议」——中国程序化交易监管史前传的一页（呼应 REGULATION
   报告时间线）
5. **零对外披露传统**：不上市、不发产品、不做 PR——除了
   Prosperity 竞赛，「低调到只有竞赛是门面」

## 六、对量化 R&D 的启示

1. **竞赛即招聘管道**：Prosperity（IMC）↔ UBIQUANT CHALLENGE
  （九坤）↔ WorldQuant Challenge——全球量化招聘的「竞赛三角」；
   dsh-quant 的生态竞争也可以是「开源竞赛」
2. **做市商的办公室地图 = 交易所地图**：阿姆斯特丹/芝加哥/悉尼/
   孟买全是期权交易所所在地——选办公室就是选交易所
3. **监管摩擦的预演**：IMC 2016 被查 → 中国 2024 程序化新规——
   外资做市商的遭遇是中国监管趋严的先行指标
