# Squarepoint Capital —— 大行自营组孵化的低调多策略量化

## 起源（2014）

2014 年成立，创始团队来自**雷曼兄弟/巴克莱的量化自营交易组**——2008
金融危机后《沃尔克规则》等监管限制大行自营交易，一批顶级量化团队
被迫独立，Squarepoint 正是这批「买方量化黄金一代」的代表。

## 演进路线

```
大行自营量化组（雷曼/巴克莱）
  → 2014 Squarepoint 独立
  → 全球多策略量化：统计套利/做市/宏观量化/商品/固收
  → 办公室：纽约/伦敦/新加坡/巴黎/日内瓦/蒙特利尔/班加罗尔…
  → 管理规模：数百亿美元级（低调未上市，公开资料少）
```

## 文化

- **低调到近乎隐身**：几乎零公开演讲、零开源、零宣传——
  「闷声做量化的样本」
- 工程师与量化研究员并重，全球分布式团队
- 与 HRT/JS 的「算法文化」不同，Squarepoint 更偏**系统化多策略平台**

## 对量化 R&D 的启示

1. **监管创造机会**：沃尔克规则逼出的大行自营组，是过去十年量化
   生态最大的供给侧变化——「环境变化里藏着新玩家的生态位」
2. **低调也是策略**：不宣传 = 不暴露人才/策略/数据——与 Jane Street
   的开放形成光谱两极，各有各的活法
3. **多策略量化平台**：与 Millennium pod 制不同，Squarepoint 是
   「系统化」多策略——组合层工具（dsh-ml/risk）的又一种组织形态
