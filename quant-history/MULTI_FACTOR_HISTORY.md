## 一、时间线：多因子模型的演进

### 阶段 0：CAPM（1964）——单因子的起点
- **Sharpe/Lintner/Mossin**：CAPM——只有一个因子（市场 β）
- 意义：第一次用"风险"解释收益——但只有市场风险
- 局限：无法解释"为什么同 β 的股票收益不同"

### 阶段 1：学术多因子（1970s-1990s）——因子的发现

| 年份 | 工作 | 贡献 |
|---|---|---|
| 1970s | **APT（套利定价理论）**（Ross）| 多因子理论框架 |
| 1976 | **Banz（规模效应）** | 小市值溢价 |
| 1980 | **DeBondt & Thaler（反转）** | 长期反转 |
| 1992 | **Fama-French 三因子** ⭐ | **市场 + SMB（规模）+ HML（价值）**——里程碑 |
| 1997 | **Carhart 四因子** | + 动量（UMD）|
| 2015 | **Fama-French 五因子** | + 盈利（RMW）+ 投资（CMA）|
| 2018 | **Fama-French 六因子** | + 动量（替代 UMD）|

**关键**：学术因子的发现 = 从"一个市场因子"到"一组风格因子"——多因子模型的理论地基。

### 阶段 2：Barra 实践（1975-）——风险的"显微镜" ⭐

| 年份 | 事件 |
|---|---|
| **1975** | **Barra 成立**（Barr Rosenberg）——第一个多因子风险模型 USE1（美国股票）|
| 1980s | USE2/USE3 迭代——风险模型商业化 |
| 1989 | **MSCI 收购 Barra** → MSCI Barra 因子模型 |
| 2000s | **CNE 系列（中国版）**：CNE4 → **CNE5**（A 股多因子模型）|
| 2010s | 全球统一：MSCI Barra 全球因子模型（GEM）|

**Barra 的贡献（为什么是"显微镜"）**：
1. **风险分解**：组合风险 = 因子暴露 × 因子协方差 + 特质风险
2. **风格因子体系**：价值/规模/动量/波动/质量/流动性等 10+ 风格因子
3. **行业/国家因子**：行业配置 + 国家暴露
4. **组合优化**：在风险约束下最大化预期收益（"炼金术"）
5. **中国落地**：CNE5 适配 A 股（涨跌停/T+1/ST 等特殊结构）

### 阶段 3：机器学习增强（2010s-）——因子的"新引擎"
- **Barra+ML**：用 ML（GBDT/神经网络）增强因子——非线性关系
- **WorldQuant/量化私募**：AI 因子挖掘（我们的 PWOL 路线）
- **深度学习因子**：端到端（Transformer 等）
- **中国实践**：A 股多因子 + ML（BarraCNE5 + ML 模型研究）

## 二、多因子选股策略的历史（实践视角）

### 2.1 选股流程的演进
```text
CAPM 时代：β 选股（买高 β 博收益）
  → 学术因子：价值/规模/动量等单因子选股
  → 多因子合成：打分法（等权/IC 加权）
  → Barra 优化：风险约束下的组合构建
  → ML 时代：因子挖掘 + 非线性合成 + 端到端
```

3. **AI 化**（2020-）：ML 因子 + 深度学习（幻方/九坤/倍漾等）
4. **现状**（2026）：多因子是主流指增的骨架 + AI 增强

## 三、Barra 模型详解（为什么是标杆）

### 3.1 核心结构
```text
R_i = Σ β_ik · f_k + ε_i
（个股收益 = 因子暴露 × 因子收益 + 特质收益）
```
- **因子暴露 β**：个股在各风格/行业因子上的载荷
- **因子收益 f**：每期因子的横截面收益
- **风险**：Var(R) = β'Σβ + 特质方差（因子协方差 + 特质）

### 3.2 风格因子体系（CNE5 中国版）
| 风格 | 含义 |
|---|---|
| 价值（Value）| 低估值溢价 |
| 规模（Size）| 小市值溢价 |
| 动量（Momentum）| 趋势延续 |
| 波动（Volatility）| 低波动溢价 |
| 质量（Quality）| 盈利/稳健 |
| 流动性（Liquidity）| 换手/流动性溢价 |
| 成长（Growth）| 增长预期 |

### 3.3 为什么 A 股用 CNE5
- 涨跌停/T+1/ST → 标准模型不适配
- 新股/次新/壳价值 → 中国特有因子
- 行业分类（证监会/申万）→ 行业因子本地化
